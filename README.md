# Features

Input multiple wall coordinates to define a floor plan

Add multiple light switches and fixtures

Check if each switch has an unobstructed view of a fixture

Uses line-segment intersection detection

# Technologies Used

Java (JDK 8 or higher)

Standard Java libraries (no external dependencies)

Installation & Setup

Ensure you have Java (JDK 8+) installed.

Clone or download this repository.

Compile the Java program:

javac ErgonomicFloorPlan.java

Run the program:

java ErgonomicFloorPlan
